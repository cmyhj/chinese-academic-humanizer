# 全文深度编辑：先理清论证，再逐句落稿

## 适用与边界

“全文优化／全面润色／深度优化”默认使用本流程。它不是近义替换后的追加检查，而是改写前的工作顺序。局部润色按实际篇幅缩小，不强制创建全篇台账。用户明确只纠错或不改句序时，以窄范围为准。

深度是理解层次，不是修改幅度。可在授权正文内重排句序、合并重复、澄清指代和段落职责；不能据此搬章节、动图表、重写公式、改数据或解锁保护文字。标题默认核对但不改；有明确标题措辞授权时才改，并保持层级、编号、书签目标和目录一致。

## 一、定范围与覆盖单元

1. 读取当前实际保存的版本，锁定快照与哈希；重扫修订、批注、用户手改及保护文字。上轮已被用户清除的记录不得恢复。
2. 依据真实正文标题与相邻章边界划章；区分目录缓存、正文、标题、图题、表格、公式、代码及前后置。不以长度阈值跳过短正文句，也不只读普通段落而漏修订中的有效文字。
3. 给本轮基线建立稳定段ID；在可审正文内建立句/分句ID。断句需识别小数、英文缩写和公式占位符，必要时人工复核。标题短语不混入正文句数。
4. 建立章节/小节覆盖清单。缺少独立正文的父标题也应检查职责与其子节关系，但不假造正文计数。允许保留，不允许漏审。

**完成条件：**目标集合明确；保护对象有理由；末章、展望及授权摘要、附录说明、致谢都有归属。不得把示例篇幅、句数、修改数写成固定门槛。

## 二、第一轮：先建立全章论证链

先通读本章及前后章交接，再拟改句。用简短内部笔记回答：本章解决什么问题、输入来自哪里、每节承担什么作用、输出如何交给下一章。不要把笔记变成正文里的模板路线图。

| 章节功能 | 主要检查 |
|---|---|
| 绪论 | 应用约束如何收敛到研究问题；现状分类是否同层；不足、目标和研究内容是否一一衔接，而非反复宣告同一问题 |
| 设计 | 需求是否先于方案；比选是否给具体收益与代价；组成、连接、动作、作用及选型依据是否分清；是否预支试验结果 |
| 建模 | 对象、假设、坐标与变量是否先定义；几何、受力、材料能力和判据是否连接；数学关系能否支持文字结论 |
| 仿真/试验 | 每组工作验证什么；方法、条件、结果与解释是否分层；局部观察是否被概括成全部工况能力 |
| 结论/展望 | 结论是否回答原问题；创新是否讲做法与区别而非重列数据；应用是否仍为可支持层级；展望是否对应真实限制 |

**完成条件：**每节职责与前后依赖可说明；重复、缺环、越位及证据跨层的问题先定位，再进入逐句改写。不能只按段首段尾抽查全章。

## 三、第二轮：明确小节与段落职责

对每段先判断“这一段让读者多知道了什么”，再读前后段；涉及跨节指代时扩大到相关小节，不能把固定三段窗口当成上下文上限。

- 区分提出问题、解释机理、描述实现、给出结果、讨论条件、归纳取舍与引出下文。不要让同一段同时做完所有任务。
- 重复信息优先保留在承担该职责的一处，其他位置删冗余或作必要承接；避免各处保留同义总结，或删除后用更长解释补回。
- 设计阶段给依据和实现，试验阶段给观测与条件，结论给可支持结果；不是把相同段落分别换成“本章”“试验表明”“综上”三次。
- 同名父子标题应先区分职责；仅在已获授权时把子题改成具体对象或任务短语，不能为避免重名改动章节层级。
- 连接词须对应真实关系：并列不写因果，先后不写同时，条件不写保证，相关不写必要。少一句连接词通常好过多一个没有依据的因果节点。

**完成条件：**调整后的段落次序和内容足以承接前后文，且没有新增研究过程；不要求每段都有总结句。

## 四、第三轮：逐句改写与完整落稿方案

句级记录至少包含：`sid / paragraph_id / 原句或分句 / 修改或保留 / 具体理由`；修改段另给完整`old / new / reason`，保留数学原子及引用锚点。

逐句检查：
1. **对象与指代：**主语是谁；“该方法/上述状态”是否唯一；机构、控制模式、执行指令和反馈状态是否被混称。
2. **语法与信息层次：**动词能否带住宾语；并列是否同层；长句是否跨多个判断；拆分是否丢失条件对后句的约束。
3. **叙述次序：**先定义后使用、先条件后结果、先构成再动作；必要时调整句序，不仅替换词汇。
4. **重复与语气：**删无信息的评价、双重转折、同义总结和翻译腔；保留正常科技长句、固定表达及真实并列。
5. **命题与证据：**本句是在描述目标、模型、仿真、观测、解释还是未来工作；动词强度是否与来源相称。

保留理由应说明该句的角色和条件，不统一填“原文通顺”。若多句合并或一句拆开，记录信息流向，并回读整段核查；不能把源句是否仍为新段子串当成人工审查结果。

**完成条件：**所有目标句有判断，实改段有完整前后文；新句与前后句连读自然。无问题的句子保留，不按配额换词。

## 五、第四轮：科学保真与跨章复核

### 1. 数字相同仍可能改变事实

对实质变化的命题，按需核对“对象—物理量/指标—条件—关系—证据来源”，不为普通修辞另建庞大事实台账。

重点拦截：
- 把一种方案的实现路径写成所有方案的必要条件，把“部分/所测”改成“全部/任意”。
- 把动态惯性改称连续运动，把可暂停性、运动连续性和动力学机制互相替代。
- 把接触长度、面积覆盖率、容差、工况种类数、重复成功率当成同一指标。
- 把选用参数写成某单项指标峰值，把综合取舍写成所有指标最优。
- 为使方案“解释充分”补写原稿没有的电路机理、控制性质、误差消除证明、硬件规格、实验失败原因或研究迭代经历。
- 将模型解释写成观测事实；将未列结果写成设备不具备能力；将潜在真空适用性写成整机通过真空验证。

### 2. 实际表格与公式优先于漂亮概括

对“持续增加、均高于基线、最大、最优、上限、所有类型成功”等词，逐格核原矩阵、工况和重复记录；对由公式得出的文字结论，核根号、系数、方向和适用域，不用扁平符号串代替公式结构。

发现矛盾时区分：原始测量值、模型参数、派生计算、定性概括与引用标识。未经授权不改原始数据；疑似派生关系不自行改成另一个数字。可按已有证据保守删去或收窄无支持的比较结论，但必须完整记录改动及未决口径；涉及核心结果且不能保守落稿时，暂停受影响项并提出最小问题。

同值不证明串用，周长也不能在未确认圆截面假设时替代实测直径或局部曲率。不要让一次审查制造新的数据错误。

### 3. 审查意见也要复核

长篇、专业密集或高风险章节可并行安排只读审查，输入必须包括原段、整段改写和相关上下文；任务要求定位、完整建议、理由与证据锚点。主代理独占合稿，不让多人改同一文件。

把编辑建议与独立审查都视为待裁定方案。尤其重核新增物理解释、控制时序、阈值排序、单位和数值换算；不要按审查者的语气或问题条数采纳。正确原句应退回保留，不能为了照收意见制造改动。

### 4. 限定不是审计口吻

用“在所测条件下”“根据该模型”“可解释为”等写清范围；只在需要时出现，不给每句加可能、仅、不能证明。不要把“没有找到记录”“本试验未单独测量”“应如何评价”堆进正文。

核查过程、资料可得性、待确认事项及编辑选择留在说明。保留有意义的科学限制，不把正常的方法与条件说明一并删掉。

**完成条件：**跨章术语、参数归属、机制、工况范围和模型/实测层级一致；新增解释有据或已撤回。技术词表、数字校验只能辅助，不能证明语义保真。

## 六、第五轮：中文摘要定稿后同步英文

1. 先按最终正文确定中文摘要，不在正文未定稿时让英文独立发挥。
2. 建立精简命题对照：任务与问题、结构及来源归属、方法与控制、结果指标、条件/范围、应用层级。按实际内容列，不固定条数。
3. 英文可以重组句法，不能只沿用旧英文改几个关键词；逐项核同一主语、因果、仿生归属、指标名称、模态和限定范围。
4. 逐项对应实际中英关键词，并核全文固定术语。中文变更后再回查英文，禁止两份摘要分别定稿后不复对。
5. 字数遵守当轮模板；没有模板时不把某个历史稿的字数、词数或指标数量当作普遍要求。

**完成条件：**中英文表达同一组可支持命题，无新增贡献、实验或更强结论；不是“数字相同即同步”。

## 七、执行、验收与交付

- 内容方案通过复核后再正式落稿。长任务可保存私有检查点；局部失败只修受影响段，保留已完成结果，不反复全文重建。
- 全文任务一次推进到授权范围结束，不在每章后要求用户说“继续”。遇到真实阻塞明确暴露，不用部分成果冒充完成。
- 按基线ID集合核覆盖、重复和遗漏，复核句级判断与最终改写仍一致。句/分句、标题、保护对象分别计数，不继承历史稿总数。
- 内容验收与Word技术验收分开：前者检查论证、对象、条件、信息密度、自然语体和摘要一致；后者按`word-tracked-revisions`验证源保护、原生修订、双态/仅拒绝本轮恢复、公式图表及排版。两者都通过才能宣称全文完成。
- 记录应能定位：逐章逐节覆盖、完整段落原/新对照、全部句级判断、保留理由、主要裁定、双语对照及待核项。普通短文本按需简化，不机械生成大套文件。
- 正式目录仅一份新稿及配套记录；候选和脚本留私有工作区。最终说明实际修改层次、验收证据和剩余边界，不用调试日志刷屏。

## 交付前反例检查

- 每段只是换了几个词，段落任务与论证断点没处理：未完成深度优化。
- 所有段末都添一句“这表明……”：优先检查新增冗余或无据推断。
- 改后更长，因为替读者补齐了原稿未提供的机理：撤回新增事实，不把可解释性当证据。
- 一律改短句或换术语以避免重复：恢复必要条件和同一概念的固定称谓。
- 因有保护规则而回避所有逻辑问题：在授权正文中处理表达和关系，真正事实缺口单列，不以保护为名只换词。
- 图表/数据校验通过便称语言完成，或文字好读便跳过修订恢复：两类验收均不成立。
