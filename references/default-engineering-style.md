# 默认文风：中文机械／机器人／航空工程学术写作

## 适用与优先级

本文件从选定的两篇《航空学报》论文和一篇南航硕士论文提炼，作为本技能默认文风，不是可选示例。每次使用技能时加载并应用；用户未另给样本时直接使用，无须再次索要论文或依赖原附件。只有核对原句或重新校准风格时才需回查原PDF。

本轮明确指令、目标学校/期刊规范与新指定样本优先于本默认；科学保真边界始终有效。三篇样本的共同写法用于默认，期刊压缩结构与学位论文章节展开分开采用。只授权文字润色时，以下结构规则用于局部表达判断，不构成重排章节、增删内容、补数据或改图表格式的授权。

## 一、语气与句法

1. 用“设计、提出、建立、采用、分析、求解、确定、完成、校核、验证”等动词说明真实工作。宾语具体到结构、模型、轨迹、参数、方法或试验，不只写“开展系统研究”。摘要和章节概述可以用动作链压缩研究过程。依据 W1、Q1、Y1、Y3。
2. 目的或条件可前置：“为满足[任务要求]，采用[方案]”；因果按机理串联：“由于[已知原因]，[做法]，从而[直接作用]”。一个句子只保留确有作用的连接词，不叠用“通过……从而……进而……保证”。依据 W2、W3、Q3。
3. 并列机构、工况和步骤可用顿号、分号、编号及“首先/其次/最后”。真实的三项研究内容无须为去AI味改成两项。方法步骤写清状态转换及停止条件，不机械打散有用的对称结构。依据 W4、Q4。
4. 用具体主语保持对象连续。只有当前指代唯一时用“该机器人/该装置/上述方法”，跨多对象时恢复名称。不为避免重复把机身、机体、平台、系统随意互换。依据 Q2、Y4。
5. 长句若承载同一任务的条件、做法及目的可以保留；并列多种动作或越过多个因果节点时拆分。拆句不能丢失原假设对后句的约束。不仿制样本的句长，不人为加入“短句有力”式断句。
6. 表达合理局限时直接说明条件或尚未完成的内容，不用“因本人能力有限”；不自动加入“笔者认为”“出乎意料”。正文与致谢的语域分开。
7. 试验称谓应写明“对象/条件＋任务”，不要只以材料或场景代替试验名称。例如研究机器人在树干上的移动时，称“树干表面爬行试验”，而非笼统的“树干试验”；若实际任务是外过渡，应按任务命名，不能一律改成爬行。后文指代唯一时才可简称。
8. 区分试验观察与由观察得出的判断。“试验表明”后的陈述句语法上成立，但不能把一次过程描述直接当作一般规律。报告特定现象可用“在……试验中，观察到……”；归纳机理可在证据支持的条件内用“……会使/会导致……”；表达关系可用“……是……的原因之一/约束条件”。“会”不是必添助词，不能靠加“会”把未经验证的因果升级为规律。避免将原因、并列动作与后果混列；将“表面起伏—接触不同步—机体倾斜及预载分配不均”按已支持的因果层次表达。

## 二、行文逻辑与章节用途

### 摘要

按“研究对象/具体需求—方案及关键做法—建模/规划/控制—验证方式—主要结果”压缩，突出真正有区分度的结构或方法。已有可靠定量指标时选最能回答问题的结果；没有数据不为了模板补数，也不强迫每篇摘要写固定数量的指标。W1/Q1/Y1分别示范多模态设计、轮腿规划及结构—规划—仿真工作链。不要把潜在用途写成已完成场景试验。

### 绪论与研究现状

从应用场景逐步收敛到任务约束，再解释现有路线的适用条件、收益和代价，最后落到本文问题。研究现状按构型、附着/推进机制、运动方式或任务功能等真实分类组织；每类用“研究者/机构—对象—方法或结构特征—展示能力—必要边界”介绍代表工作，不铺纯名单或逐图报幕。只引用当前稿实际支持的工作，不继承样本关于技术领先、历史发展或市场地位的事实。

期刊可在引言末直接给方案与贡献；学位论文可另列研究内容及章节安排。不能为了靠近样本强制给短论文添加章级路线图，或删除已确认的学位论文结构。依据 W1—W2、Q1—Q3、Y2。

### 总体与结构设计

按“设计要求—总体方案—组成与布局—部件连接及驱动—作用过程—选型/参数依据”说明。具体段落先讲装置由什么组成，各部件位于何处、如何连接，再讲如何动作及为何这样设计。需要比选时，以当前任务的空间、载荷、运动和制造约束解释取舍，不只给好/差评级。依据 W2—W3、Q2、Y3—Y5。

机构动作按动力传递链写：驱动元件→传动件→约束下的运动→执行部件→目标状态；控制阶段按触发条件→执行动作→状态转换写，不只说“实现协同”。原稿缺动作细节时标记待补，不从样本移植机构。

### 建模与理论分析

先交代对象、假设与坐标系，定义变量和状态，再写几何/运动/受力关系、推导与求解，最后说明判据或适用范围。引式可用“可表示为”“由式……可得”；式后用“式中，……为……”解释新符号，符号多时依模板用符号表。依据 W3、Q5—Q6、Y10。

只有原问题确有层次时，才用“简化模型—加入约束—修正模型—相同指标比较”逐层加严；不把三级模型作为通用硬模板。优化结果须保留局部/全局、启发式解/精确解的区别，不照搬样本笼统的“最优”。依据 Y7—Y8。

### 运动规划与控制

先写任务、可用信息、约束和输入输出，再说明为何选基础算法、加入什么改进、如何按阶段或模块执行。规划可按“状态—轨迹—边界/终止条件”展开；控制可按信号来源、回路/模块、执行分配、仿真工况组织。保留状态名、构型编号和坐标系的一致性，不将航空纵向通道、三角步态等领域做法强套到别的系统。依据 Q3—Q6、Y7、Y10。

### 仿真与试验结果

先明确验证对象与证据类型，再给软件/设备、模型/样机、工况和输入、过程/结果、量化现象、机理解释及判据。多种试验可在节首概括，并与后续内容对应；不用每节重复整套设备说明。解释曲线时区分指令、模型输出、估计量和实测量；区分最大值、稳态值、阈值、均值和范围。依据 W4—W5、Q7—Q8、Y11。

评价“满足要求”时，写清哪项结果对应哪条已有设计指标。能用同一条件下的指标连接设计校核与后续验证时，保持指标和单位一致；不同条件不得强行闭环。仿真不能改写为样机实测，未来实物试验不能写成已经完成。依据 Y6、Y12。

### 小结、结论与展望

小结回答本章完成什么、得到什么可支持的认识，不把各小节目录再复述一遍。全篇结论对应研究问题，按“对象—做法—所得结果/能力”归纳，不新增参数、文献或结论。未来工作对应真实局限和未覆盖工况，不用泛化口号，也不机械附加局限段。依据 W6、Q9、Y12—Y13。

## 三、术语与固定表达库

固定表达是可选句法支架，方括号必须用当前稿已有内容填入；缺内容不能借句法编造。避免每段重复同一支架。

| 功能 | 默认表达方式 | 使用约束 |
| --- | --- | --- |
| 提出研究 | 针对[具体任务/约束]，设计/提出[对象/方法] | 不用抽象“复杂问题”替代已知对象 |
| 设计依据 | 根据[已有要求/参数]，确定[布局/参数/方案] | 依据必须可定位，不凭空补标准 |
| 组成布局 | [对象]主要由[部件]组成；[部件]设置于[位置] | 组成和位置必须与图/事实一致 |
| 作用机理 | 通过[动作/结构关系]，改变[直接物理量]，实现[功能] | 每个因果节点有依据，不能跳成泛化鲁棒性 |
| 方案取舍 | 与[可比方案]相比，[收益]，但[代价/限制] | 可比维度一致，不人为捏造对比 |
| 定义与假设 | 设[变量]为[物理含义]；在[假设]下…… | 不改变符号、方向、单位及适用域 |
| 引入图表 | [结构/曲线/参数]如图/表[编号]所示 | 必须已存在且指向正确对象，不新增图号 |
| 引入公式 | [关系]可表示为……；式中，[符号]为[含义] | 不用文字替换原生公式；不重复定义已明确符号 |
| 动作阶段 | 当[条件]时，[执行动作]；达到[条件]后进入[状态] | 区分同时/先后/直到，不能改控制时序 |
| 描述结果 | 在[工况]下，[指标]为/不超过/保持在[原有结果] | 不凭模板生成数值、改善幅度或统计显著性 |
| 判定证据 | 仿真/试验结果表明，在[范围]内，[结论] | 证据类型明确；理论证明合法时可用“证明” |
| 后续方向 | 针对[已暴露限制]，后续可[具体工作] | 不写原文没有的失败、经历或未完事项 |

术语使用纪律：
- 首次需要时采用中文术语、英文全称与缩写，之后固定用法；常识性词不强塞英文。既有文稿术语遵循作者和领域规范，不为模仿样本全篇重新翻译。
- 构型、模态/模式、状态、阶段各有功能：结构布局或构型变化、运行方式、当前状态、过程分段不任意轮换；按本文已有定义执行，不强行一刀切改名。
- 位置不等于姿态，位姿包括相应位置与姿态信息；轨迹/航迹、轮腿/轮足、机身/机体并非在所有上下文可互换。需按具体结构和定义选择，不能靠同义替换去重。
- 运动学、静力学、动力学、强度校核、稳定性分析、控制性能、仿真验证及实物试验分别描述相应证据，不相互冒充。
- 保留“足端/足末端、支撑相/摆动相、工作空间、稳态误差、超调量、调节时间”等已定义术语；这些只是样本示例，不是所有论文必须加入的词表。

## 四、从样本中明确排除的写法

- 不复制“极其广泛”“十分迅速”“重要意义”等无具体支撑的赞誉；原文有不等于默认应加。
- 不复制ABDragon/ABDargon等样本命名不一致、全角数字抽取结果、“仿真仿真”等错字、错序、编号空格及中英标点混排。
- 不把仿真节偶发的“实验结果”转成实物验证，也不把数值仿真中的“真实值”理解为传感器实测。
- 不采用“消除奇异位置”等可能强于前文“解决运动唯一性”的转述；保留具体物理含义与证据范围。
- 不强制每段末给判断、每章恰好三级模型、固定几条贡献、固定句长或固定“本文”频率。
- 不因本默认允许“基于”“如图所示”“由……可知”而堆砌，是否修改仍按信息功能判断。
- 对“满足要求”“稳定”“最优”“可忽略”“无超调”逐项核条件；样本文风不是这些主张的证据。
