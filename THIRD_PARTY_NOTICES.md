# Sources and third-party notices

## Editing guides

This project adapts ideas from the following editing guides. It combines them with an independently written Chinese engineering style guide and a context-first editing workflow. It does not include their repository contents wholesale.

- **AIScientists-Dev/academic-humanizer** — https://github.com/AIScientists-Dev/academic-humanizer — MIT. Reference points: claim–evidence alignment, scholarly voice, preserving data and citations, and author-style calibration.
- **redbaronyyyyy-eng/humanizer-zh-academic** — https://github.com/redbaronyyyyy-eng/humanizer-zh-academic — MIT. Reference points: Chinese formulaic openings/endings, repetitive paragraph structures, filler and vague attribution. This project does not adopt its detection-rate claims, noise budget or forced personal reactions.
